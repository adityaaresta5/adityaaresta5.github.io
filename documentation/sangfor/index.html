Tentang seri ini

Seri ini dibagi enam modul yang saling menyambung. Part 1 jadi fondasi sebelum kamu menyentuh console: membaca diagram arsitektur, menjelaskan cara kerja storage terdistribusi, dan memilih jumlah replica dengan alasan yang jelas. Part 2 lanjut ke praktiknya — dari server kosong di rak sampai node yang bisa dibuka di browser, lengkap dengan 13 layar installer dan checklist verifikasi sebelum node boleh masuk cluster. Part 3 membedah konfigurasi dasar: login platform, pembagian 4 lapis interface, agregasi bersama switch, lisensi USB, sampai deployment cluster multi-node. Part 4 menuntaskan inisialisasi cluster dan virtual storage: peran cluster controller, alokasi VXLAN overlay, pemilihan mode interface storage, aturan arsitektur disk group (1 SSD cache per group), rumus kapasitas usable (Slide 36), hingga uji gateway storage. Part 5 menuntaskan operasi virtual machine: alokasi vCPU dan RAM hingga 4 TB, mode disk RAW vs QCOW2, alur pembuatan VM baru dari ISO, perbandingan 3 metode clone (instant full, link, full), import berkas OVA/OVF, ekspor VM aman, hingga instalasi driver paravirtualisasi Sangfor vmTools. Part 6 menuntaskan virtual network dan NFV: memvirtualisasikan jaringan fisik menjadi aNet, konfigurasi Physical Edge, port group VLAN, distributed virtual switch (DVS) dengan VXLAN, virtual router (vRouter), deployment NFV (vNGAF, vIAM, vADC), serta pemantauan trafik dengan Traffic Mirroring dan Network Insight.
